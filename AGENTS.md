# AGENTS.md - Centia BaaS

The global hard rules for working with Centia BaaS live in `skills/centia-rules/SKILL.md`.

Read that skill first on every Centia-related task. It covers tool priority, runtime-vs-provisioning boundaries, security and auth baselines, the destructive-operations confirmation policy, and routing to the task-specific `skills/centia-*/SKILL.md` files.

This file is kept so agents that discover instructions via `AGENTS.md` (Junie, Codex, etc.) still find the rules. Claude Code users get the same rules through the `centia-rules` skill in the plugin.
